# TGA Konverter

Wandelt beliebig gewählte Bilddateien (PNG, JPG, BMP, GIF) in das `.tga`-Format um, das der Client für Icons erwartet.

## Was du hier tun kannst

- Mehrere Dateien auf einmal auswählen, jede mit editierbarem Zielpfad, oder einen gemeinsamen Zielordner für alle setzen.
- Direkte Vorschau vor der Umwandlung.

## Wichtig zu wissen

Dieselbe Umwandlungslogik läuft **automatisch** im Hintergrund, wenn du im Item Editor ein Icon auswählst - dieser Bereich hier ist für alle Fälle gedacht, in denen du unabhängig davon einfach nur Bilder konvertieren willst.
