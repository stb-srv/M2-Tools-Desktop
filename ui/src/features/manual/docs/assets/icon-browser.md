# Icon-Browser

Durchsucht rekursiv alle Item-Icons (`.tga`) im Client-Ordner, mit Vorschau-Kacheln.

## Was du hier tun kannst

- Als eigener Bereich einfach zum Stöbern/Prüfen, welche Icons bereits vorhanden sind.
- Als **Auswahl-Dialog im Item Editor** ("Aus Icon-Browser wählen…") - dieselbe Ansicht lässt sich direkt beim Anlegen/Bearbeiten eines Items öffnen.

## Wichtig zu wissen

Thumbnails werden erst geladen, wenn sie sichtbar werden (mit Seitenweise-Nachladen), damit auch sehr große Icon-Ordner flüssig bleiben.
