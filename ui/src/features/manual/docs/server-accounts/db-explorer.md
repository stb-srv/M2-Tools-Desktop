# Datenbank-Explorer

Freie Tabellenansicht für **jede** Tabelle in der Datenbank - für alles, wofür es (noch) keinen eigenen, spezialisierten Editor gibt.

## Was du hier tun kannst

- Eine beliebige Tabelle auswählen, durchblättern, filtern/suchen.
- Zeilen bearbeiten - die Primärschlüssel-Spalte wird automatisch erkannt statt "id"/"vnum" anzunehmen.

## Wichtig zu wissen

Das ist bewusst der generische, "rohe" Weg - für Items, Shops, Mobs, Aufwertungen, Kisten, Accounts gibt es jeweils eigene, komfortablere Editoren mit Kontext-Wissen über die Bedeutung der Spalten. Nutze den Datenbank-Explorer für alles andere, oder wenn du wirklich den rohen Inhalt einer Tabelle sehen willst.
